# 11462294 Jewelry — Premium E-commerce Website

Professional jewelry storefront ready for GitHub Pages.

## Features
- 12 products with local images
- Visible prices
- Category filters
- Search
- Price sorting
- Quick View
- Functional cart with quantities, remove and subtotal
- Cart saved in browser localStorage
- Responsive mobile layout
- Custom logo and favicon

## Checkout
The checkout button is intentionally demo-only and does not process payments. Connect a real payment platform before accepting orders.

## GitHub Pages
Upload all files to the root of `11462294.github.io`, then enable Pages from `Settings → Pages → Deploy from branch → main / root`.

Product information, prices, materials and reviews are sample content and should be replaced with real business information before commercial use.
